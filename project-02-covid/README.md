I explored a global COVID-19 dataset of over 429,000 records using SQL and Tableau to understand how the pandemic affected different countries differently. I found that Nigeria's reported infection rate of 0.12% significantly understates actual spread due to limited testing infrastructure and misdiagnosis as malaria. Europe had the highest death toll despite not having the most cases, largely because it was hit before vaccines existed and has an older population. My recommendation was that underreported data in developing countries is a critical gap that distorts global pandemic response decisions.
## Dataset
Data sourced from Our World in Data COVID-19 dataset.
Download link: https://github.com/owid/covid-19-data
